## Context

We need a desktop framework for Codex Portátil that:
- Runs entirely from a USB drive (no system dependencies)
- Maintains <5s cold start on USB 3.0
- Works on Windows, macOS, Linux
- Binary size matters (user may have limited storage)

## Options Compared

| Metric | Tauri 2 | Electron |
|--------|---------|----------|
| Binary size (compressed) | ~4-8 MB | ~165 MB |
| Cold start | 0.3-1s | 1-3s |
| Memory usage | ~50-150 MB idle | ~300-500 MB idle |
| Security sandbox | Webview2/WebKitGTK/WKWebView | Chromium sandbox |
| Portability | Excellent | Poor (large footprint) |

## Decision: **Tauri 2**

### Rationale

1. **43x smaller binary**: Critical for USB distribution and storage-constrained users
2. **Faster startup**: Meets the <5s cold start requirement easily
3. **Better security**: Rust backend with stricter sandboxing
4. **Active development**: Tauri 2 is in active use by major projects

### Trade-offs

- **Smaller ecosystem**: Fewer packages than Electron (mitigated via careful dependency selection)
- **WebView dependencies**: Platform-specific webviews (documented workarounds needed)
- **Rust learning curve**: Minimal for a React frontend; backend Rust core still needed

## Implementation Plan

1. Use Tauri 2 with TypeScript/React frontend
2. Backend: Rust crate for file watcher, IPC, and SQLite operations
3. AI sidecar: Separate process (llama-server) with JSON-RPC IPC
4. Frontend: TipTap for block editor, sigma.js for knowledge graph
