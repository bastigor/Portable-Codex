# ADR-003: Portability Architecture

## Context
Must install on Windows 10/11, macOS (Intel + Apple Silicon), Ubuntu/Fedora via single command. No admin rights needed. No pre-installed runtimes (Node, Python, Rust, Docker). Must not write outside project root.

## Decision
**Monorepo with portable installer script:**
- Single `install.sh` / `setup.py` that detects OS/architecture and delegates to a minimal bootstrap.
- Packages: `/app/bin/` (platform-specific binaries), `/models/` (GGUF models), `/data/` (vaults, SQLite index, config, cache, logs).
- All paths resolved relative to executable via env vars or config file (`PORTABLE_ROOT`).
- Installer verifies SHA-256 checksums and optional signatures.
- Idempotent: can be re-run safely.

## Alternatives
| Option | Pros | Cons |
|---|---|---|
| Full Docker image vs portable script | Isolated, reproducible | Heavy; requires Docker or pre-install |
| Electron app vs Tauri 2 | More mature | Larger binary, WebView dependency |

## Rationale
Single command install on any OS. No network needed at runtime (downloads only in installer). Strict mode: all data under `/data/`.

## File layout (root of pendrive):
```
/app/          # binaries per platform
/models/       # GGUF models
/data/         # vaults, index SQLite, config, cache, logs
/scripts/      # installers, bootstrappers
/docs/         # docs, ADRs, manifests
```
