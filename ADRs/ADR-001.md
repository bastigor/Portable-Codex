# ADR-001: Tech Stack Decision

## Context
Project "Codex Portátil" is a local-first Personal Knowledge Management (PKM) app combining Obsidian vaults (.md frontmatter, wikilinks, graph) with Notion-like structured views and database queries. Must run 100% offline on CPU/GPU, be portable to Windows/macOS/Linux/exFAT/NTFS, and use Rust for the core.

## Decision
**Stack:**
- **Core language:** Rust (for performance, safety, no runtime dependencies)
- **Frontend framework:** Tauri 2 (lightweight web frontend, single binary, avoids WebView2/WebKitGTK issues on varied machines)
- **Editor engine:** ProseMirror / TipTap (or Lexical) for block-based Markdown editing
- **AI inference sidecar:** llama.cpp (GGUF quantized models), Rust bindings or `llama-server` process
- **Database:** SQLite WAL mode with FTS5, sqlite-vec for embeddings, backlinks/tables
- **File watcher:** Background incremental indexer with debounce

## Alternatives Considered
| Option | Pros | Cons |
|---|---|---|
| Electron vs Tauri 2 | Electron more predictable; Tauri smaller binary | WebView2 dependency risk on Linux/macOS; Tauri avoids it |
| React/Svelte vs ProseMirror | Faster dev; Svelte lighter | Block editor needs custom implementation (ProseMirror/TipTap provides it) |
| Node.js vs Rust | Easier package management | Slower startup, larger binary footprint |

## Rationale
Rust + Tauri 2 gives the smallest installable binary and zero runtime dependencies. ProseMirror-based editor ensures Obsidian-compatible Markdown round-trip. llama.cpp sidecar handles local AI without network calls.

## Consequences
- Single binary per platform (no npm/pip/node needed)
- Build artifacts in `/app/` on install; no system packages required
- WebView2 risk mitigated by Tauri's sandboxed approach
