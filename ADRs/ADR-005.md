# ADR-005: Network & Privacy Policy

## Context
Zero network requests at runtime. No telemetry, no accounts, no cloud.

## Decision
**No outbound calls in app:**
- All inference via local llama.cpp sidecar (no API keys).
- Indexing incremental in background with debounce.
- Downloads only during explicit install script (verified checksums).

## Alternatives
| Option | Pros | Cons |
|---|---|---|
| Full internet sync vs offline-only | Cloud backup, collaboration | Violates Principle 3 & 4 |

## Rationale
Privacy-first. User never sees network activity. Install script can download pre-packaged models if offline mode not available.
